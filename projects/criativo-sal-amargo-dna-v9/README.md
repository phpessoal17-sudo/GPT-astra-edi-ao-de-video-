O conector limita o corpo de cada envio a 16 MiB. Para reduzir o pacote, foram omitidas somente as mixagens intermediarias assets/mix_raw.wav e assets/mix_master.wav, regeneradas pelo codigo. A trilha original e o stem de SFX permanecem completos, com os bytes preservados. O MP4 final permanece identico ao export entregue.

Reconstrucao: instale Python, FFmpeg e as fontes indicadas em README.md, execute `pip install -r requirements.txt` e `python src/render.py` dentro da pasta extraida. O renderizador preserva os arquivos existentes; use uma copia de trabalho conforme o manual.

A foto original tem 240x240 pixels. O anuncio evita alegacoes terapeuticas e detalhes do rotulo nao comprovados. O DNA v9 foi adaptado a este produto; a documentacao distingue evidencias, adaptacoes e limites de revisao perceptual.

As somas Git blob SHA-1 e os tamanhos estao em DOWNLOAD_MANIFEST.json. O ZIP conserva os CRCs originais dos 33 arquivos preservados e inclui dois documentos sobre o pacote de download.
