# Módulo 04 — Cinematografia e direção

- Composição define hierarquia: sujeito, apoio e profundidade em planos distintos.
- Movimento de câmera deve expressar intenção: aproximação para intimidade, recuo para contexto, pan para descoberta, estabilidade para clareza.
- Manter direção de olhar, eixo, escala e luz coerentes entre planos relacionados.
- Usar contraste de luz e cor para orientar o olhar; preservar tons de pele e detalhes nos realces.
- Em 9:16, proteger rosto, legendas e CTA das áreas de interface. Elementos principais devem ler em tela pequena.
- Em motion, construir o quadro final antes de animar. Entradas convergem para posições estáveis; animação não corrige layout fraco.
