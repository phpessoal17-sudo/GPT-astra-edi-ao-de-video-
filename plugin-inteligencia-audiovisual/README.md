# Masterpiece Audiovisual Intelligence

Pacote portátil de conhecimento e operação audiovisual, versão 1.0.0.

O pacote consolida os métodos realmente disponíveis neste repositório e nesta conversa: diagnóstico de mídia, montagem orientada pela mensagem, transcrição local verificável, motion design 2D/HTML, masterização conservadora, áudio original sintetizado, controle de qualidade e entrega. Ele também preserva diretrizes criativas do usuário: acabamento premium, narrativa clara, efeitos motivados, autonomia operacional e economia de créditos.

## O que este pacote é

- Uma skill instalável em ambientes compatíveis com `SKILL.md`.
- Uma base de conhecimento modular em Markdown.
- Um conjunto de prompts, configurações e schemas portáteis.
- Um runtime Python/FFmpeg reaproveitado do Editorial Video Engine já testado neste projeto.

## O que este pacote não é

- Não é um plugin publicado automaticamente no catálogo da plataforma.
- Não transfere memória entre contas de forma automática.
- Não inclui licenças de softwares comerciais, modelos de IA ou credenciais.
- Não executa tracking, rotoscopia, 3D ou restauração neural sem ferramenta verificada.

Consulte `docs/INSTALACAO.md`, `docs/DIAGNOSTICO.md` e `docs/RELATORIO_IMPLEMENTACAO.md`.
